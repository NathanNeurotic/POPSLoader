ROOT CAUSE HIERARCHY
================================================================================

Level 1: General PS2 Architecture
  └─ ExecPS2 switches EE context
     └─ RPC client connections are per-context

Level 2: RPC Service Architecture
  └─ fileXioInit() establishes RPC connection in current context
     └─ Cannot be used from different context after ExecPS2

Level 3: POPSLoader Specific
  └─ Parent-context path violates this constraint
  └─ Embedded-loader path respects this constraint
  └─ Using wrong path causes silent failure


SOLUTION
================================================================================

❌ DO NOT USE:
   fileXioInit() in parent -> fileXioMount() in parent -> ExecPS2() to child

✓ DO USE:
   ExecPS2() to child -> fileXioInit() in child -> fileXioMount() in child

OR

✓ ALTERNATIVE:
   fileXioMount() in parent -> SifExitRpc() -> ExecPS2() -> 
   child uses pre-mounted state
