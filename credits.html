Credits

POPStarter, POPSLoader, and this documentation archive are the work of many people across more than a decade. This page credits them as accurately as the record allows.

★ Documentation

ShaolinAssassin

Author of the original POPStarter documentation wiki — the single most important source this entire archive is built from. Every reference page on this site exists because ShaolinAssassin took the time to document POPStarter for the community. This whole project is, first and foremost, a preservation of that work.

POPStarter & POPS

krHACKen
Author of POPStarter and its official CHANGES.TXT changelog — the launcher this entire site documents. Nearly every behaviour, command, and config byte here is his work.
Sony Computer Entertainment
Created POPS, the PS1-on-PS2 emulator POPStarter wraps. Acknowledged here by checksum only — it is not distributed.

The leading, still-maintained community per-game fix pack for POPStarter, plus countless individual game fixes.

The PATCH_#.BIN / TROJAN_#.BIN compatibility-mode system, the LibCrypt cracks, and the cumulative fix bundles.

On this page

POPStarter Documentation Archive — community-recovered from the Wayback Machine (ShaolinAssassin's popstarter-documentation-stuff wiki) and krHACKen's r13 changelog, cross-checked and merged across snapshots. Built for the POPSLoader project.

POPStarter is krHACKen's homebrew launcher. POPS is Sony's PS1-on-PS2 emulator and is not distributed here — it is referenced by checksum only. “TROJAN” is POPStarter's own name for a patch file, not malware. Some external links were intentionally removed. Built on the documentation of ShaolinAssassin and krHACKen — see Credits.
