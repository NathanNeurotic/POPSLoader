Historical appendix: provenance, timeline, and recovery method

The de-facto primary documentation - ShaolinAssassin's Bitbucket wiki (bitbucket.org/ShaolinAssassin/popstarter-documentation-stuff) - and krHACKen's own changelog are NOT actually lost. The wiki survives in the Wayback Machine (the CDX API lists ~70-90 snapshotted pages: special-cheats, cheat-engine, compatibility, igr, configuration-table, usb/smb/hdd-mode, quickstart-*, uLE_kHn, multi-disc, vmc, bios-osd-handlers, general-note, faqs, popstarter-changelog, and more), and krHACKen's complete CHANGES.TXT ships inside the canonical 2019-06-05 r13 package on archive.org. The retrieval recipe that works in this environment: WebFetch is blocked from web.archive.org, but curl against a timestamped raw URL (web.archive.org/web/id_/) returns clean HTML; button-combo hotkeys that render as images are decoded by grepping the raw HTML for the archived glyph filenames; and the Bitbucket downloads CDX surfaces recoverable assets (discs_pooper.exe, debug_and_halt.ppf, compatibility_modes.7z, cue2pops, batcher, etc.).

KEY TIMELINE (anchored to CHANGES.TXT): WIP01 introduced the HDD __.POPS multi-VCD launch type; WIP02 (2014-08-22) added the 8-slot force-compatibility table and made the IGR skin/IRX loaders default-on; Beta 8 (2015-10-23) added the SMB/ps2host/napLink backends and embedded the PFS wrapper; Beta 9 added the mc1 module fallback; Beta 11 (2015-11-11) added SMB port selection, made IPCONFIG.DAT optional, and fixed POPS#-folder reads; Beta 12 (2015-11-24) added $FORCEPAL and SMB authentication and made $SAFEMODE functional; Beta 13 (2015-12-07) added the BOOT.ELF exit chain, fixed the cheat-engine 'hook+8', $C0 and $USBDELAY/$C0 bugs, removed the function skipper (freeing $412) and the ps2host/napLink launchers; Beta 15 (2016-09-18) added CD-lid/DISCS.TXT multi-disc and the 480p calc; Beta 16 (2016-11-20) integrated $IGR0..5/$NOIGR/$D2LS as CHEATS.TXT commands, repurposed $412 as HDTVFIX, and added the untested soft-reset hotkey; Prototype 2 (2017-05-27) added $42F test mode (0x04); and the r13 final (2019-06-05) fixed $IGR5. A subtle point worth carrying onto the site: the IGR behaviour modifiers existed as standalone TROJAN files from 2014 but became $IGR CHEATS.TXT commands only in Beta 16.

Key facts

POPStarter is the launcher/patch layer; POPS is Sony's emulator primary history

Effect: POPStarter (krHACKen) is the launcher and patch/cheat layer wrapped AROUND Sony's PS1-on-PS2 POPS emulator (POPS.ELF / SLBB-00001). POPStarter loads per-game assets (CHEATS.TXT, PATCH/TROJAN, BIOS/OSD, VMCDIR/DISCS), applies the cheat engine and compatibility modes, and hands off to POPS to actually emulate. 'POPStarter' is a distinct project from the modern Lua-based POPSLoader fork.
Scope: Whole architecture. Canonical package = 2019-06-05 r13 Beta.
Conflicts: Don't conflate POPStarter (krHACKen) with POPS (Sony) or with POPSLoader (El_isra -> NathanNeurotic).
POPStarter.ELF reads CHEATS.TXT/PATCH_#.BIN, then launches POPS to emulate the VCD

Recovery method for the lost ShaolinAssassin wiki near-primary history

Effect: The 'lost' ShaolinAssassin Bitbucket wiki (bitbucket.org/ShaolinAssassin/popstarter-documentation-stuff/wiki) is fully recoverable: the Wayback CDX API lists ~70-90 snapshotted pages, and curl against a timestamped raw URL of the form web.archive.org/web/<TS>id_/<original> returns clean page HTML (HTTP 200). WebFetch is blocked from web.archive.org, but curl works. Button-combo hotkeys that render as images are recovered by grepping the raw HTML for the archived glyph filenames. The Bitbucket downloads CDX surfaces recoverable assets (discs_pooper.exe, batcher, compatibility_modes.7z, cue2pops, debug_and_halt.ppf, etc.).
Scope: Corpus-building methodology.
Conflicts: The official all-in-one sample CHEATS.TXT download is NOT recoverable (every snapshot 302s to an expired Bitbucket S3 URL).
curl 'http://web.archive.org/cdx/search/cdx?url=bitbucket.org/ShaolinAssassin/popstarter-documentation-stuff/wiki*' then web.archive.org/web/<TS>id_/<url>
📎 Method note from agents 1/2/4/5; Wayback CDX API

From the official thread — project status & provenance

Sourced from the official psx-place POPStarter thread.
krHACKen items are authoritative.

  • The source was never lost or "rewritten from scratch." krHACKen kept it private and made occasional
    cumulative fixes; hugopocked is a co-fixer. (krHACKen — corrects a long-running rumor)
  • Definitive public release set: the final POPSTARTER.ELF is dated 2019-06-05 (USB drivers dated
    2019-01-14; a 2019-06-14 repackage also exists) — there is no hidden newer ELF. The last fix-pack is
    TROJAN_7.BIN (r7, 2020-05-20). Avoid the older "RIP06" build; prefer 2019-06-05. (Ripto / hugopocked)
  • 2020-08-10 wLE_kHn build note: "Moved loader.elf to 0x00092000 due to kernel corruption." — a
    concrete loader relocation from the wLaunchELF-integration build. (quoted, krHACKen)
  • Project effectively closed around 2020, with the source private. The halt is attributed to a
    "Frankenstein SDK" and the OPL/Jay-Jay conflict of the era; ongoing fixes now come from hugopocked rather
    than krHACKen, and RetroGEM-style per-game-ID integration will not happen. (El_isra / 60fpshacksrock)
  • ShaolinAssassin's wiki was being rebuilt (~70%, private) after the original bitbucket was lost; the
    archive.org snapshots (2017 & 2020) are the surviving record — which is what this site is reconstructed from.
    (ShaolinAssassin / HWNJ)
On this page

POPStarter Documentation Archive — community-recovered from the Wayback Machine (ShaolinAssassin's popstarter-documentation-stuff wiki) and krHACKen's r13 changelog, cross-checked and merged across snapshots. Built for the POPSLoader project.

POPStarter is krHACKen's homebrew launcher. POPS is Sony's PS1-on-PS2 emulator and is not distributed here — it is referenced by checksum only. “TROJAN” is POPStarter's own name for a patch file, not malware. Some external links were intentionally removed.
