# Top new findings

1. Compatibility MODE 0x07 ($COMPATIBILITY_0x07) exists and fixes missing-textures problems (e.g. Tomb Raider III) - the base report's mode list stopped at 0x06.
2. $412 is the SetGsCrt/HDTVFIX hack in r13, NOT a 'function skipper.' The skipper lived at $412 only pre-Beta-13 and was removed 2015-12-07 (~10 KB saved); the byte was repurposed for HDTVFIX in Beta 15/16. The base report conflated two eras.
3. The ENTIRE 32-byte config table ($410-$42F) is recovered and double-sourced (lost wiki + live ELF hexdump). Verified default bytes: 00 00 00 02 40 00 03 01 00 00 00 00 00 00 00 00 01 00 01 01 01 01 01 01 01 00 01 01 01 01 01 03. Sixteen offsets the base never had are now documented (incl. $424 IGR-exit-method which gates the BOOT.ELF chain, $429 VMC count, $42F test mode 0x04).
4. USB delay is TWO offsets: $413 (embedded-USB-module access delay, r13, fixes 'drive not detected') vs $417 (obsolete PFS-wrapper delay, 'NOT USED' in r13). And $USBDELAY_# patches POPS for streaming - it does NOT fix detection. The base report listed $USBDELAY_# without this critical distinction.
5. TROJAN files have TWO roles in the primary wiki, not one: IGR-behaviour modifiers (TROJAN_0..5 = $IGR0..5, TROJAN_9 = 'No 2nd Pad in IGR') AND cumulative per-game game-fix bundles (TROJAN_7 = 'cumulative r6, fixes as of 2020-05-20'). The base conflated TROJAN with 'a patch filename.' PATCH_0.BIN (== $NOIGR) is also a distinct stock file.
6. Exact $IGR0..5 button combos pinned from the canonical CHANGES.TXT (IGR0/3 = L1+L2+R1+R2+X+Down, IGR1/4 = Start+Select, IGR2/5 = L1+L2+R1+R2+Start+Select; 0/1/2 open the menu, 3/4/5 terminate). This CORRECTS the base $IGR5 gloss and the widely-mirrored PT-BR manual, which swaps $IGR4/$IGR5. $IGR5 was broken until the 2019-06-05 final.
7. The 'SMB requires a debug build' belief is DECISIVELY REFUTED: SMB was a normal feature from Beta 8 (2015-10-23, 'NOT password protected, fixed port 445'); the only debug caveat is that startup debug text can't be skipped in SMB mode (cosmetic).
8. The 2020 PATCH_9.BIN's real purpose is sharper than 'disables bugged ELF loader': it RESTORES IGR/quit-to-OPL which BETA-13 broke (2020-03-21, via the IGR thread, MD5 9db1e18b..., 188 B) - a fully separate binary from the stock $NOPAL PATCH_9.BIN.
9. The PATCH/TROJAN header-number integrity check is documented (build-ID at offset Ah, version at Ch=0x03): POPStarter silently refuses to load a file whose filename number doesn't match its header, and auto-skips stale versions - the mechanism behind the 2015 WIP06-Beta-3 'integrity check failures' changelog line. Recovered MD5/size fingerprints for every IGR PATCH/TROJAN.
10. The 'lost' ShaolinAssassin wiki is NOT lost - it is fully recoverable via the Wayback CDX API + the id_ raw-snapshot endpoint (curl, not WebFetch). Image-rendered hotkeys are decoded from archived glyph filenames; the Bitbucket downloads CDX surfaces recoverable assets (discs_pooper.exe, debug_and_halt.ppf, compatibility_modes.7z, cue2pops). NEW recoverables also include the SLOT0/SLOT1 + $429 VMC-count fact, the full OSD.BIN v1 header, the POPS-'flashes-the-whole-VMC' mechanism, $SCANLINES, $UNDO_GAME_FIXES, the Rumble-Always-On codes, and a complete Jackie Chan PAL LibCrypt code block.
