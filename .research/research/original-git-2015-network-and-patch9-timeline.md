# Developer-source chronology: 2014 PAL PATCH_9, 2015 SMB modules/$NOPAL, and 2020 IGR PATCH_9

**2026-10-11 research continuation for draft PR #580.** This records contemporaneous developer/forum source claims. It is not executable guidance, independent PS2 hardware validation, or proof that the referenced original archives can currently be downloaded. Do not import or redistribute proprietary Sony POPS binaries.

## Source/custody confidence

- **Documentary high:** identifiable developers directly describing historical features in dated discussion posts. Statements are observations/instructions for **their release dates**, not proof of current behavior.
- **Strong current-byte evidence:** current 188-byte named NOPAL archive SHA-256 `e07446f307cee99be54795d83bc1cf645def4c4aeba384aea474343ca0015d5d`, `PATCH_9.BIN` SHA-256 `bdbf309adbb8a28a8af66f085a3a0f430efd2e9679668a7efd07c093b11b3fca`. See [hosted patch report](original-git-hosted-patch-archive-inspection.md).
- **Unverified original bytes:** no downloaded 2015 `POPStarter_Net_Modules_for_mc0.zip`, 2017 `NOPAL_PATCH.7z`, or original 2017 `network_modules.7z`. No original member size/hash crosswalk exists.
- **No equivalence inference:** `2015 .zip` ≠ `2017 .7z` ≠ `2020 SMB Quickstarter .zip` merely because they served the same *kind* of drivers. Similarly, identical `PATCH_9.BIN` basenames do not imply identical patches.
