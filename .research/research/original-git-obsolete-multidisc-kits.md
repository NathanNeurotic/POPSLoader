## Removed limitations and alternate workflow

The old author cautioned that disc-combining could result in a game that did not work. Before a native disc-swap mechanism was available, the text suggested saving just before a disc boundary, exporting the save from a POPS VMC, continuing disc 2 on a PS1 emulator or retail PS1, and then importing the resulting save back to the POPS VMC. This **historical workaround is distinct** from the current recovered `multi-disc.md`'s manual VMC transfer between POPS disc folders and from the native disc-swap feature.

The author originally pointed at an old community-made ngemu/Box kit collection. The current reconstructed `multi-disc.md` still references a `Disc_Combining_Kits.7z` package, which the site's download records mark as intentionally excluded. The removed regional title catalogue and the warning about the specific Chrono Cross kit are not present in directly checked recovered `vcd.md`, `multi-disc.md`, `Game-Compatibility.md`, `compatibility.md`, `Home.md`, `related-stuff.md`, `troubleshooting-games.md`, `known-bugs.md`, or `popstarter-changelog.md`.

**No executable or binary kit is included, linked as a live download, or proposed for restoration.** The possible-virus warning is a historical allegation by the original document, not an independent malware determination. This file preserves metadata for maintainer review only.
