## ⭐ TIER 0 — krHACKEN AUTHORITATIVE (developer's own corrections/clarifications — add these FIRST and flag as canonical)

### Cheats
- **`$IGR5` = OPL-style IGR combo (Select+Start+L1+L2+R1+R2) with NO YES/NO exit popup.** [FLAG: krHACKen] Disambiguates the $IGR0–5 family — this is the variant people actually want for a clean OPL-like exit. → **cheats** (krHACKen, p15)
- **`$SAFEMODE` is ONLY for raw hexadecimal cheats**, NOT the built-in `$` named commands ($IGR, $NOPAL, $WIDESCREEN, etc.). [FLAG: krHACKen] Corrects widespread over-use. → **cheats** (krHACKen, p10)

### Config (direct hex offsets — krHACKen-specified)
- **`$HDTVFIX` = config-table offset `412h`, value 0→1.** [FLAG: krHACKen] Lets users hex-edit POPSTARTER.ELF directly when CHEATS.TXT route green-screens on internal HDD. → **config** (krHACKen, p10)
- **Offset `413h` = USB-HDD detection/retry count (default 2).** Raise to 5+ for stubborn/slow USB HDDs. (jolek, medium-confidence, but pairs with krHACKen's 412h to map the $410–$42F table byte-by-byte.) → **config** (jolek, p1)

### Storage / Config
- **HDD multi-partition scan order is `__.POPS → __.POPS0 → __.POPS1 … → __.POPS9`.** [FLAG: krHACKen-authored doc] `__.POPS` is NOT aliased to `__.POPS0` (unlike mass:/mass0:). The correct *second* partition is `__.POPS0`. Corrects a common assumption. → **storage** (Peppe90 quoting krHACKen, p12)
- **OPL config files (`conf_elm.cfg`, `conf_elmz.cfg`) inside the POPS folder silently kick POPStarter back to OSD** (no error). [FLAG: krHACKen-confirmed] Failure-signature gotcha. → **troubleshooting** (krHACKen, p1)

### Patches / Trojans (the developer's own farewell fix-pack)
- **`TROJAN_7.BIN` is krHACKen's final cumulative "goodbye" fix-pack** — patches POPStarter globally, applied to ALL games. [FLAG: krHACKen/hugopocked] Revision history: r6 (2020-05-20) → r7 (2020-05-20, "unhook code just fixed"). Post-dates the r13/2019-06-05 final ELF; NOT merged into it. → **patches/downloads** (krHACKen + hugopocked, p8/p17/p18)
- **TROJAN_7 should ONLY be used on games NOT already covered by hugopocked's per-game fixes** — stacking both ADDS crashes. [FLAG: hugopocked] → **patches** (hugopocked, p18)
- **POPStarter validates the number inside the PATCH/TROJAN header against the filename and refuses to load on mismatch.** [FLAG: ShaolinAssassin] You cannot just rename `TROJAN_7.BIN`→`TROJAN_0.BIN`; the embedded header number must be hex-edited too. The digit is a *slot* (0–9), not a version. → **patches** (ShaolinAssassin, p8)

### Troubleshooting (IGR / BOOT.ELF exit chain)
- **Black screen after IGR "YES" = your BOOT.ELF is incompatible.** [FLAG: krHACKen] Two fixes: (1) disable POPStarter's internal ELF loader, or (2) repack BOOT.ELF with a different packer (NRLPack). With the loader disabled, IGR drops to the PS2 Browser. → **troubleshooting** (krHACKen, p15)
- **`PATCH_9.BIN` disables the bugged ELF loader and restores normal IGR.** [FLAG: krHACKen] A named, attached patch with a documented effect not in the base cheat-command list. Caveat: with it in place, OPL-DB can no longer launch PS1 games (only wLE_kHn launching works). → **patches/troubleshooting** (krHACKen, p4)

### Driver myths corrected
- **You CANNOT add external HDD drivers to the `__common/POPS` folder to fix HDD mode.** [FLAG: krHACKen] USB drivers renamed MODULE_#.IRX don't help in HDD mode; `ATAD.IRX` is incompatible with the other drivers; `HDDLOAD.IRX` is the MBR KELF loader (wrong module, needs an EE-side partner). Kills a persistent community myth. → **troubleshooting** (krHACKen + sp193, p5)

### History
- **Source was never lost/rewritten — krHACKen only makes occasional cumulative fixes; source stays private; hugopocked is a co-fixer.** [FLAG: krHACKen] Corrects the "lost source / rewrote from scratch" rumor. → **history** (krHACKen, p5)

### Naming standard
- **Display name belongs in `conf_apps.cfg` as `display_name=path`, NEVER in the filename.** [FLAG: krHACKen] OPL set this standard in v0.8. PSXtreme/POPStarter Game Installer intentionally generates opaque unique filenames (`HWC…VCD`); tools that read display names from filenames (OPL Manager) are doing it wrong. → **config/storage** (krHACKen, p13)

## CONFIG

- **CHEATS.TXT filename must be UPPERCASE (`CHEATS.TXT`, not `CHEATS.txt`)** or cheats silently fail — case-sensitive on HDD/pfs, tolerant over SMB. This is the real root cause behind the "$HDTVFIX works on USB but not SMB" and "green-screen on HDD" reports. → **config/troubleshooting** (krHACKen + jolek, p10/p17) **[consolidates 3 findings]**
- **FF9 ships with `$COMPATIBILITY 0x04` enabled by default (since WIP02)** — concrete evidence of POPStarter's built-in per-game default-config table. → **config** (Peppe90, p8)
- **USB access delay (the `413h`-region byte) — default `0x02`; raise to 4–5 for slow devices, external HDDs, or when VMC files get re-created every boot.** Use a POPSTARTER.ELF prebuilt with higher delay. Especially relevant with BDMAssault/MMCEMAN. → **config** (Okeanos, p19)
- **SMB debug-mode overlay cannot be disabled** — hard-coded in the 2019-06-05 build, no CHEATS.TXT/config switch. → **config** (VanhuX, p9)

## COMPATIBILITY

- **Merged multi-disc ISOs break per-game fixes** — fixes are keyed to the game ID in SYSTEM.CNF; a merged Crash 1+2+3 ISO carries the wrong ID so the Temple Ruins freeze-fix never fires. Run clean single-disc rips. Applies to MGS and other commonly-merged titles. → **compatibility/storage** (Peppe90 + El_Patas, p9) **[high value]**
- **`$COMPATIBILITY` modes are NOT universally effective — several are no-ops per game:** Mode 4 never integrated for Chrono Trigger/Xenogears (doesn't fix sound); Mega Man X4 never had Mode 1; SOTN has Mode 1 but keeps old problems. Xenogears flicker and Chrono Trigger area/menu sound-slowdown are **unfixable** by any mode. → **compatibility** (El_Patas, p2/p3) **[corrective]**
- **PAL PS1 games scroll/roll vertically through HDMI adapters; `$NOPAL` stops the scroll but off-centers the image** (fix via XPOS/YPOS). PAL-patcher / 50–60Hz handling is the suspect. → **compatibility/troubleshooting** (R3dRapt0r39, p18)
- **Soul Blade & other CD-read-sensitive games on USB: format FAT32/exFAT with 16 KB cluster size.** Larger clusters → corrupt loads/crashes. (SMB & internal HDD work regardless.) → **compatibility/storage** (hugopocked, p19)
- **Aspect-ratio anomaly:** POPS games can render ~1:1 squashed with grey side-borders instead of 4:3 on some slim/OPL/ethernet setups — relevant to `$XPOS/$YPOS/$DWSTRETCH/$DWCROP`. → **compatibility** (HE1NZ, p6, low-conf — note as open)

**Per-game datapoints worth a compatibility table:**
- King's Field (JP, Eng-patched): needs `$COMPATIBILITY 0x04` to avoid slowdowns. (Peppe90, p9)
- C-12: Final Resistance (SCES_033.64): `$COMPATIBILITY_0x07` partly fixes missing textures (mode is incomplete — cutscene speech/subs missing). (jolek, p2)
- Mega Man 8 / X4 (USB/HDD): `$CODECACHE_ADDON_0` in CHEATS.TXT fixes charge-beam/voice SFX (preferred over swapping to PSP BIOS). (El_Patas, p3)
- Tekken 3 (PAL): in-game scanline generator hotkey **Select+R1+R2** fixes bottom-screen artifacts. (Peppe90, p3) — *also documents a live hotkey not in the captured set.*
- RE3 (SLUS-00923): completable with GameHacking.org "Skip Door Transition" code + PSP 6.60 BIOS, no compat mode. (hugopocked, p1)
- Tomb Raider 1 USA: only Rev0 works untouched; Rev1–6 need krHACKen's per-revision patches (psx-place Resources > PS3 > Tools) for both levels AND music. TR2 USA Rev0–3 all fine. Gold ports won't load levels / have no music fix. (bananana, p12)
- **Known multi-track audio bug:** newer TR revisions and Air Combat lose all CD music/voice tracks even when levels load. (Peppe90, p12)
- Speedball 2100 (US): TROJAN_7 clears the load freeze but then reports "no controller in port 1" — separate unfixable emulation bug shared by a few games. (El_Patas, p10)

## STORAGE / FILES

- **Full official-OPL HDD layout to list PS1 games as Apps:** `__.POPS` partition (≤128GB, VCDs) + `__common\POPS` (POPS.ELF/IOPRP252.IMG + per-game folders/VMCs/textures/patches) + `+OPL` (pfs0) APPS folder with renamed POPSTARTER.ELF copies + ART covers + `conf_apps.cfg`. VCD/ELF/folder/cover names must all match. → **storage** (Peppe90, p12) **[high value, complete recipe]**
- **TROJAN path on internal HDD: `hdd0:/__common/POPS/TROJAN_7.BIN`** (alongside POPS.ELF). → **storage** (El_isra, p14)
- **Dual POPS-binary resolution:** POPStarter reads `POPS_IOX.PAK` (USB) OR `POPS.ELF + IOPRP252.IMG` (`__common/POPS`) depending on what's mounted. Symptom of an incomplete HDD install: launching shunts straight back to wLE when the USB stick is absent. → **storage/troubleshooting** (SG-17, p14)
- **Multi-disc layout:** `DISCS.TXT` lists both VCDs; `VMCDIR.TXT` contains ONLY the CD1 folder name; SLOT0/SLOT1.VMC live in the CD1 folder; per-disc CD1/CD2 subfolders. Tool: `discs_pooper-bambuch0-fix`. → **storage** (ShaolinAssassin, p19)
- **IRX loader: up to `MODULE_0.IRX`–`MODULE_9.IRX`, loaded from POPS/ root ONLY — never from the per-game VMC folder.** For special devices: `SIO2MAN.IRX` MUST be `MODULE_0.IRX`; order matters. → **storage/config** (ShaolinAssassin + AkuHaK, p19)
- **SMB mode requires network modules on a memory card (`mc?:/POPSTARTER/`)** — SMB without a physical MC is impossible. → **storage** (jolek, p5)
- **Only internal HDD and USB are valid backends — no CD/DVD-disc loading.** → **storage** (Berion, p7)

## TROUBLESHOOTING

- **OPL AUTO BDM/SMB/HDD combo hangs HDD-launched POPSTARTER ELFs on black screen** (HDD light stuck, needs power-off). Workaround: set BDM & SMB to **Manual**. Confirmed OPL-side bug, not POPStarter. → **troubleshooting** (Ripto + TnA, p15) **[high value, reproducible]**
- **`$HDTVFIX` forces 480i and breaks 240p on CRTs** — some installers (PSF Batchkit Manager) silently add it. Remove it to restore 240p. → **troubleshooting/cheats** (BloodRaynare, p15)
- **OPL DB fork (not stock OPL) corrupts TROJAN loading** — use official OPL for PS2 games. → **troubleshooting** (HWNJ, p10)
- **SMB on Win10:** enable "SMB 1.0/CIFS" (PS2 is SMBv1-only) AND either turn off password-protected sharing OR (better, per Arcueid) create a dedicated Windows user with a password and grant share access. Share a subfolder, not the whole drive. → **troubleshooting/storage** (jolek + Arcueid, p1/p9)
- **SCPH-700xx consoles often need extra `USBD.IRX`/`USBHDFSD.IRX` via the IRX loader** to fully init HDD (PS-logo freeze otherwise). Also: VCDs go in `hdd:/__.POPS/` (with the dot). → **troubleshooting** (jolek, p4)
- **DS3 over Bluetooth drifts/goes haywire under POPStarter** (all builds) — workaround is wired USB IRX files. → **troubleshooting** (CosmicScale, p11)
- **VMC fragmentation can make a save vanish or a game unlaunchable; defragging the drive restores it.** → **troubleshooting** (Peppe90/HWNJ, p9)

**Open/unresolved signatures worth recording as known-issues:**
- SCPH-77004 (PAL slim): universal black-screen even when SMB debug shows all-Done; signature `FFS Wrapper r6a : 35` then black. (exo12, p18)
- SMB VMC save-dir not auto-created over Samba; manually creating it hangs on "Validating the resource directory." (SicariusLeif, p7)
- SMB launch can fail with `LOGON has failed (0)`. (RandomGuy2024, p16)
