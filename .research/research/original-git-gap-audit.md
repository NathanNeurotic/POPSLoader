# Original wiki Git-history gap audit (research only)

**Source:** AstroSnail-supplied `wiki.zip`, an original ShaolinAssassin Bitbucket wiki Git clone with 2,140 commits (2016–2024). Its contents are not being imported or rewritten in this PR.

## Audit rules
- Compare source HEAD, prior revisions, and deleted pages with the existing Wayback-recovered `.research/wiki/` corpus and site.
- Classify candidates as **missing**, **partially preserved**, **already preserved**, **superseded**, or **requires manual verification**.
- Keep historical technical claims date-scoped. Do not treat older documentation as current compatibility guidance.
- Preserve original attribution, URLs and commit fingerprints when recording findings.
- Do not upload historical binaries or merge the archive into repository Git history.
