# **Special Cheats – Automated Codes**

______________________________________________________________________________________________________________

Some useful commands have been automated. Here are them :

- **Sample :** [here](https://bitbucket.org/ShaolinAssassin/popstarter-documentation-stuff/downloads/CHEATS.TXT)

Some game codes do patch the memory area where the PS OSD is loaded, causing crashes and other garbage… </td> </tr> <tr> <td> $COMPATIBILITY_0x## </td> <td> Activates a <a href="https://bitbucket.org/ShaolinAssassin/popstarter-documentation-stuff/wiki/compatibility">compatibility mode</a>. </td> <td> <strong>##</strong> is a hexadecimal value. You can write as many $COMPATIBILITY_0x## as you want. </td> </tr> <tr> <td> $CODECACHE_ADDON_0 </td> <td> For games that lag badly or stall randomly. </td> <td> If compatibility mode and mode 0×04 doesn’t fix that doesn’t fix your issue. Do not use it by default on all your games, because most games will stop working with it. </td> </tr> <tr> <td> $SUBCDSTATUS </td> <td> A variant of $COMPATIBILITY_0×05. </td> <td> </td> </tr> <tr> <td> $FAKELC </td> <td> Loads a null LibCrypt magic word into the cop0 register. </td> <td> May be needed by some discs that have a messed up LC protection. </td> </tr> <tr> <td> $SMOOTH </td> <td> Enables the <a href="https://bitbucket.org/ShaolinAssassin/popstarter-documentation-stuff/wiki/smooth">smooth texture</a> mapping at startup. </td> <td> Just for the records : value is $S0003390 <a href="https://bitbucket.org/ShaolinAssassin/popstarter-documentation-stuff/commits/00000001">00000001</a>. </td> </tr> <tr> <td> $NOPAL </td> <td> Disables POPStarters’ PAL patcher. </td> <td> Can be done using a <a href="https://bitbucket.org/ShaolinAssassin/popstarter-documentation-stuff/downloads/NOPAL_PATCH.7z">PATCH_#.BIN</a> file. Not meant to convert NTSC games to PAL. </td> </tr> <tr> <td> $FORCEPAL </td> <td> Forces the activation of the PAL patcher (POPS will run it PAL) and patches the BIOS region code to Euro (shows the boot screen in PAL). </td> <td> Useful for PAL VCDs that don’t have a valid license text in their bootsector. Can be done using a <a href="https://bitbucket.org/ShaolinAssassin/popstarter-documentation-stuff/downloads/FORCEPAL_PATCH.7z">PATCH_#.BIN file</a>. </td> </tr> <tr> <td> $480p </td> <td> Forces 480p. </td> <td> Not compatible with $XPOS, $YPOS, $DWSTRETCH, $DWCROP &amp; NOT reliable ATM. Does not deal with stuff like HUDs, texts/fonts, menus, 2D backgrounds… </td> </tr> <tr> <td> $EYEFINITY </td> <td> Same as $WIDESCREEN, with 3×16:9 aspect ratio. </td> <td> Does not deal with stuff like HUDs, texts/fonts, menus, 2D backgrounds… </td> </tr> <tr> <td> $XPOS_#### </td> <td> Centers the screen horizontally. </td> <td> <strong>####</strong> is a number (decimal, negative values not supported). Works only in PAL and NTSC modes. Default value : 640. Value lower than 640 will move the screen on the left, value higher than 640 will move it to the right. Not compatible with $480p. </td> </tr> <tr> <td> $YPOS_## </td> <td> Centers the screen vertically. </td> <td> <strong>##</strong> is a number (decimal, negative values not supported). Not compatible with $480p. </td> </tr> <tr> <td> $HDTVFIX </td> <td> Enables SetGsCrt hack. </td> <td> Helps with the HDTVs that can’t deal with the interlaced resolutions thru component (plain green screens and other rubbish displayed otherwise).
