This is an overview of code coverage, not a blanket compatibility certification. For current regressions and dated hardware evidence, always use STATE.md and QA_REGRESSION_MATRIX.md.

i.Link Existing device-menu placeholder Deferred until RiptOPL has proven hardware support

The Ethernet menu supports choosing SMBv1 or experimental USB + UDPFS for POPStarter, with appropriate server, driver and setup requirements. Neither POPStarter's UDPFS path nor Ember's network handoff should be advertised as certified solely because host tests pass. Consult UDPFS details.

POPSLoader's Ember development guide documents separate Ember settings and its keep-IOP launch path. i.Link is intentionally excluded from the PR #600 completion gate. Retain existing unsupported UI, revisit when RiptOPL demonstrates the device on real hardware, and do not call the resulting Ember release full-device parity.

On this page

POPStarter Documentation Archive — community-recovered from the Wayback Machine (ShaolinAssassin's popstarter-documentation-stuff wiki) and krHACKen's r13 changelog, cross-checked and merged across snapshots. Built for the POPSLoader project.

POPStarter is krHACKen's homebrew launcher. POPS is Sony's PS1-on-PS2 emulator and is not distributed here — it is referenced by checksum only. “TROJAN” is POPStarter's own name for a patch file, not malware. Some external links were intentionally removed. Built on the documentation of ShaolinAssassin and krHACKen. Historical wiki Git source supplied by AstroSnail — see Credits.
