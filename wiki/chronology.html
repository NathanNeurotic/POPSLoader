Chronology – from SLBB-00001 to POPStarter

Date Event
2003 Bishi Bashi Stepchamp 3 downloaded from PSBBN. Tho POPS is hardly linked to this game and because of its native features which are not used in it (VMC, vibration, analogic control, CDDA tracks support…), we can think POPS was made for something bigger. Selling PS1 classics games – like PSN – via PSBBN was maybe SONY’s plan for POPS.
2004/06 HDLoader release. Bishi Bashi Stepchamp 3 removed a bit later from PSBBN – perhaps because of the fear of piracy and POPS’ weak protection once decrypted.
2004/10 PS2 slimline case release.
2007 Proper RAW dump of the HDD partition PP.SLBB-00001.
2008/05/30 RAW dump uploaded to third part host service, named as “PP_SLBB-00001.rar”, 76,7MB sized.
2010/02/07 Decrypted files from the dump uploaded to third part host service (POPS = 3.166.988 bytes – the POPS executable, crc32 1ef0a3a7, md5 355a892a8ce4e4a105469d4ef6f39a42). The REAL leak of “Sony’s official PSX emulator for PS2 HDD”.
Unknown POC1 : first POPS hack/rape. Allows the user to rung “unauthorized” PS-X code by the injection of the executable into the PlayStation BIOS. In other words, it’s now possible to play PS1 homebrews with POPS. It’s the heart of POPStarter OSD.BIN handler feature. POPS is still protected against disc image replacement/alteration tho.
2013/01/07 After some days of tests, conan14 finally found a way to change the 2nd mounth path of the virtual drive and spread a launcher. Commercial games can now be launched with POPS.
2013/01/22 POC2 release on a russian private w@rez website.
Unknown A secret project is elaborated by never-named PS2 developers. GUI, VMC selector, BIOS handler, USB support, cheat engline, a fully working IGR… planned.
2013/02/01 Leak of files and detailled instructions about how to use the “POC2”:“https://bitbucket.org/ShaolinAssassin/popstarter-documentation-stuff/wiki/poc2-pops-00001-era at theisozone. It’s not presented as a POC. Quickly, it will be named POPS-00001 and several (hexedited) bundles-repacks of the POC2 will be availiable for download, including high-unsecure experimental stuff (the famous 48 Bit HDDOSD dump) – and presented as “Free HDBoot 2.0” (FHDB is not in work yet).
2013/02/07 Public psx-scene mis-announcement : “ NEWS: Sony’s official PSX emulator for PS2 HDD leaked (POPS-00001)”:psx-scene.com via Wayback – POPS project maintainers start to consider abording it.
2013/02/14 First public mention of the secret project.
2013/03/07 – 2013/03/12 POPS project cancelled. No announcement about it. We will know on 2013/03/12.
2013/03/12/ First public mention about POPStarter (as a continuation of the cancelled project) by krHACKen, currently in test and already in rev7. Only one version is planned : the “PATINFO” one (which means POPStarter will be HDDOSD compatible only).
2013/03/19 Plans changed. POPStarter is still in test and currently in his 8th revision. 4 versions are in work : “PATINFO”, “PORTABLE”, “LAUCHER” & “KEXEC”. POPstarter released is delayed because of a bug in the “KEXEC” version.
2013/04/09 POPStarter Revision 9 – first public release @ASSEMblergames.

On this page

POPStarter Documentation Archive — community-recovered from the Wayback Machine (ShaolinAssassin's popstarter-documentation-stuff wiki) and krHACKen's r13 changelog, cross-checked and merged across snapshots. Built for the POPSLoader project.

POPStarter is krHACKen's homebrew launcher. POPS is Sony's PS1-on-PS2 emulator and is not distributed here — it is referenced by checksum only. “TROJAN” is POPStarter's own name for a patch file, not malware. Some external links were intentionally removed.
