Compatibility modes :

If your game is poorly emulated, you can try to enable a compatibility mode to see if it helps.

Compatibility mode Description File Name Cheat code

| 0×01 | help restoring the music/voices in several games | PATCH_1.BIN | $COMPATIBILITY_0×01 |

| 0×02 | a variant of mode 0×01, with a second hack for not breaking the MDECoding of FMVs (was designed for the Colony Wars series) | PATCH_2.BIN | $COMPATIBILITY_0×02 |

| 0×03 | can be used if the mode 0×01 doesn’t provide the expected results | PATCH_3.BIN | $COMPATIBILITY_0×03 |

| 0×04 | prevent the emulator from writing a garbage value in two of the virtual GPU registers (fixes slowdowns, flickering, and many other glitches) | PATCH_4.BIN | $COMPATIBILITY_0×04 |

| 0×05 | made for fixing the cutscenes of the PAL Resident Evil: Director’s Cut | PATCH_5.BIN | $COMPATIBILITY_0×05 |

| 0×06 | disable the OSD shell of the emulator’s built-in BIOS, making some games that freeze on startup run | PATCH_6.BIN | $COMPATIBILITY_0×06 |

Caution : Modes 0×01, 0×02, 0×03 and 0×05 cannot be enabled in the same time or combined. These are variants of the same hack and they are conflicting, so use only use one of them at a time. Please let us know (at ASSEMblergames) if you managed to solve a problem in your game by forcing modes, so I could integrate the fix in POPStarter.

How to use a mode ?

3 options :

  1. Using a PATCH_X.BIN file;

  2. Using a CHEATS.TXT file;

  3. Hardcoding the mode into POPStarter (see configuration table).

Using PATCH_X.BIN file
Copy the PATCH file in the VMC directory of your problematic game then test the game;
If the compatibility mode doesn’t solve any problem in your game, delete the PATCH file from the VMC directory and redo the operations with the next PATCH file.

Using CHEATS.TXT file
See 6. Features section.

POPStarter Documentation Archive — community-recovered from the Wayback Machine (ShaolinAssassin's popstarter-documentation-stuff wiki) and krHACKen's r13 changelog, cross-checked and merged across snapshots. Built for the POPSLoader project.

POPStarter is krHACKen's homebrew launcher. POPS is Sony's PS1-on-PS2 emulator and is not distributed here — it is referenced by checksum only. “TROJAN” is POPStarter's own name for a patch file, not malware. Some external links were intentionally removed.
