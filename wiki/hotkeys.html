Hotkeys

📎 Recovered from the ShaolinAssassin wiki · snapshot 20240910140014

Hotkeys

Hotkeys Description Notes
+ + Native In-Game-Reset. Can be changed using the IGR Behaviour Modifiers.
+ + Enables the smooth texture mapping. Can be done using $SMOOTH special command in CHEATS.TXT file.
+ + Disables the smooth texture mapping.
+ + Turns the scanlines generator ON.
+ + Turns the scanlines generator OFF.
+ + + Opens the PS1 CD lid. (1)
+ + + To Insert Disc 1 (DISCS.TXT line 1).
+ + + To Insert Disc 2 (DISCS.TXT line 2).
+ + + To Insert Disc 3 (DISCS.TXT line 3).
+ + + To Insert Disc 4 (DISCS.TXT line 4).
+ + + Closes the PS1 CD lid.
+ + + PS1 software reset system.

(1) If used a with BIOS.BIN, MC manager and CD Player can be reached pressing the hotkeys at game startup. Closing the lid will run the game.

On this page

POPStarter Documentation Archive — community-recovered from the Wayback Machine (ShaolinAssassin's popstarter-documentation-stuff wiki) and krHACKen's r13 changelog, cross-checked and merged across snapshots. Built for the POPSLoader project.

POPStarter is krHACKen's homebrew launcher. POPS is Sony's PS1-on-PS2 emulator and is not distributed here — it is referenced by checksum only. “TROJAN” is POPStarter's own name for a patch file, not malware. Some external links were intentionally removed.
