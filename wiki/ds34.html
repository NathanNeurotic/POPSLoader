[DS3] Use DualShock 3 Controller with POPStarter

  • Credits : belek666 for the DualShock 3 modules.

Notes :

  • works only with WIP 06 betas & RIP 06, does NOT work with the prototypes (due to a bug affecting the IRX loader).

  • modules compiled and provided by belek666 – 2017/06/25 @ASSEMblergames.

Downloads :

  • DualShock 3 modules – USB mode

  • DualShock 3 modules – Bluetooth mode

These modules are ready to use – you only need to download and copy them into your POPS folder as they are. Do not copy them into a VMC game folder, they won’t work from there.

POPS/MODULE_1.IRX
POPS/MODULE_2.IRX

FYI :

  • MODULE_1.IRX = USBD.IRX

  • MODULE_2.IRX = usb_pademu.irx / bt_pademu.irx

You can switch from analog to digital mode by pressing (PS) + Select – with $D2LS in a GAME/CHEATS.TXT file.

POPStarter Documentation Archive — community-recovered from the Wayback Machine (ShaolinAssassin's popstarter-documentation-stuff wiki) and krHACKen's r13 changelog, cross-checked and merged across snapshots. Built for the POPSLoader project.

POPStarter is krHACKen's homebrew launcher. POPS is Sony's PS1-on-PS2 emulator and is not distributed here — it is referenced by checksum only. “TROJAN” is POPStarter's own name for a patch file, not malware. Some external links were intentionally removed. Built on the documentation of ShaolinAssassin and krHACKen — see Credits.
